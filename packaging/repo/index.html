LynxRDP package repositories

Signed APT and RPM repositories for the LynxRDP server. A server installed from a release package already knows this repository; the commands below are for setting it up by hand.

One command

On any supported distribution with a desktop environment installed:

curl -fsSL https://guitar24t.github.io/lynxrdp/install.sh | sudo sh

It sets up this repository, installs lynxrdp-server, enables the service and checks that it is running. It refuses, without changing anything, on a host that has no desktop environment, and says how to install one.

Debian and Ubuntu

curl -fsSL https://guitar24t.github.io/lynxrdp/lynxrdp-packages.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/lynxrdp-archive-keyring.gpg
sudo curl -fsSL -o /etc/apt/sources.list.d/lynxrdp.sources \
  https://guitar24t.github.io/lynxrdp/lynxrdp.sources
sudo apt update && sudo apt install lynxrdp-server

RHEL, AlmaLinux, Rocky and Fedora

sudo curl -fsSL -o /etc/yum.repos.d/lynxrdp.repo \
  https://guitar24t.github.io/lynxrdp/lynxrdp.repo
sudo dnf install lynxrdp-server

lynxrdp-packages.asc (ASCII) · lynxrdp-archive-keyring.gpg (apt keyring)

Layout

apt/dists/stable is the Debian archive; rpm/el9/x86_64 and rpm/el9/aarch64 are the yum repositories. Release candidates are versioned 0.1.0~rc.N, which both package managers rank below the final 0.1.0.
